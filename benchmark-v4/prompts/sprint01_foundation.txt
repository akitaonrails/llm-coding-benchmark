SPRINT 1 — Foundation.

Build a Ruby on Rails 8 application: a RubyLLM-powered chat app (a minimal ChatGPT-like SPA). Use Hotwire (Turbo/Stimulus) and Tailwind. Persist conversations and messages in the database (Active Record). Use the latest RubyLLM gem configured to talk to OpenRouter (read OPENROUTER_API_KEY from the environment; never hardcode or commit secrets). Provide a Dockerfile and docker compose config to run it locally. Document setup in README.md.

Follow proper Ruby on Rails best practices throughout. Write proper automated tests — unit/model tests AND system/feature (Capybara) tests for user-facing flows — and keep them green. Keep the code secure and idiomatic (strong params, scoped queries, authorization, migrations with indexes, no N+1 queries), keep RuboCop/Brakeman/bundle-audit clean, and keep the app runnable. When using a gem whose API you are unsure of (e.g. RubyLLM), study its actual API in the bundle before using it — do not guess method names. Use git: at the END of this task, commit your work with clear, atomic, well-described commit message(s). Do not stop to ask questions; implement fully and finish.
